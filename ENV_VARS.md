# Required Environment Variables

This document lists all environment variables required for production deployment.
**Never commit actual values to the repository.**

## Backend (Render Web Service)

| Variable | Description | Example value |
|---|---|---|
| `SECRET_KEY` | Django secret key (50+ random chars) | `django-insecure-...` → auto-generated by Render |
| `DEBUG` | Must be `False` in production | `False` |
| `ENVIRONMENT` | Deployment environment | `production` |
| `DATABASE_URL` | PostgreSQL connection string | `postgresql://user:pass@host/db?sslmode=require` |
| `ALLOWED_HOSTS` | Comma-separated allowed hostnames | `course-management-api.onrender.com` |
| `CORS_ALLOW_ALL_ORIGINS` | Allow all CORS origins | `False` |
| `CORS_ALLOWED_ORIGINS` | Comma-separated allowed frontend origins | `https://course-management.vercel.app` |
| `CSRF_TRUSTED_ORIGINS` | Comma-separated trusted CSRF origins | `https://course-management.vercel.app` |
| `FRONTEND_BASE_URL` | Base URL of the frontend app | `https://course-management.vercel.app` |
| `SECURE_SSL_REDIRECT` | Redirect HTTP→HTTPS (set False behind proxy) | `False` |
| `SESSION_COOKIE_SECURE` | Secure session cookies | `True` |
| `CSRF_COOKIE_SECURE` | Secure CSRF cookies | `True` |
| `TRUST_PROXY_HEADERS` | Trust `X-Forwarded-Proto` header | `True` |
| `USE_X_FORWARDED_HOST` | Trust `X-Forwarded-Host` header | `True` |
| `CELERY_BROKER_URL` | Redis URL for Celery broker | `rediss://default:pass@host:port` |
| `CELERY_RESULT_BACKEND` | Redis URL for Celery results | `rediss://default:pass@host:port` |
| `CLOUDINARY_URL` | Cloudinary connection string | `cloudinary://key:secret@cloud_name` |
| `EMAIL_BACKEND` | Django email backend | `django.core.mail.backends.console.EmailBackend` |
| `PAGE_SIZE` | API pagination page size | `20` |

## Frontend (Vercel)

| Variable | Description | Example value |
|---|---|---|
| `VITE_BASE_API_URL` | Backend API base URL | `https://course-management-api.onrender.com/api/v1` |
| `VITE_BASE_URL` | Backend base URL (for non-API calls) | `https://course-management-api.onrender.com` |

## Notes

- `DATABASE_URL` is automatically provided by Render when you link the Render PostgreSQL database to the service.
- `SECRET_KEY` can be auto-generated by Render (use the `generateValue: true` option in `render.yaml`).
- `CLOUDINARY_URL` format: `cloudinary://API_KEY:API_SECRET@CLOUD_NAME` — found in your Cloudinary dashboard.
- `CELERY_BROKER_URL` and `CELERY_RESULT_BACKEND` use the same Upstash Redis URL (use the `rediss://` TLS URL).
